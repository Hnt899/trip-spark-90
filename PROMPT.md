## 1. Проблемы с SSL-сертификатами для доменов ts-travel.by и ts-travel.online **Описание проблемы:** - Домен `https://ts-trip.com` работает нормально (SSL есть). - Домены `https://ts-travel.by` и `https://ts-travel.online` не открываются по HTTPS. - При попытке открыть эти домены браузер выдаёт ошибку `ERR_SSL_PROTOCOL_ERROR` или `ERR_CONNECTION_REFUSED`. **Что нужно сделать:** - Проверить, есть ли SSL-сертификаты для этих доменов в `/etc/letsencrypt/live/`. - Если нет — получить сертификаты через Certbot: ```bash certbot certonly --standalone -d ts-travel.by -d www.ts-travel.by -d ts-travel.online -d www.ts-travel.online

Обновить конфиг Nginx (/opt/trip-spark-90/deploy/nginx/default.conf):

Добавить блоки server для ts-travel.by и ts-travel.online с правильными путями к сертификатам.

Убедиться, что в каждом блоке есть location /travelpayouts для проксирования запросов к бэкенду.

Перезапустить контейнеры после изменений.



2. Страницы Справочная, Блог, Путеводитель не открываются

Описание проблемы:

При переходе на /reference, /blog, /guide открывается пустая страница или ошибка 404/500.

Возможно, проблема в роутинге React или в том, что бэкенд не отдаёт данные для этих страниц.

Что нужно сделать:

Проверить логи бэкенда:

bash
docker compose logs app --tail 50

Проверить, что в server/index.js зарегистрированы все необходимые роуты.

Проверить, что фронтенд собран корректно (в папке dist есть все файлы).

Если страницы используют CMS-контент, проверить, что база данных содержит нужные записи.



3. API для поиска городов (автодополнение) не работает

Описание проблемы:

На главной странице в форме поиска авиабилетов поле «Откуда» и «Куда» не показывает подсказки.

В консоли браузера ошибки Mixed Content или 404 на запросы к /travelpayouts.

Что нужно сделать:

Проверить, что бэкенд-прокси работает:

bash
curl http://46.173.27.193:4000/travelpayouts?term=Моск

Если бэкенд не отвечает — перезапустить контейнер app.

Проверить, что в nginx/default.conf есть блок location /travelpayouts с проксированием на http://app:4000/travelpayouts.

Проверить, что в src/lib/travelpayouts.ts фронтенд использует правильный URL (должен быть /travelpayouts или полный URL с HTTPS).

Если проблема в Mixed Content (запросы с HTTPS на HTTP), настроить прокси через Nginx, чтобы запросы шли по HTTPS.
