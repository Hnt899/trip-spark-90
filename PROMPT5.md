У меня есть проект trip-spark-90, развёрнутый на VPS (Ubuntu, Docker, Nginx). Осталось две проблемы.

## Проблема 1: Белый экран на /blog, /reference, /guide

**Наблюдаемое поведение (из скриншотов):**
- Страница `/reference` загружается, но затем становится белой.
- В Network видно, что запросы к API (`/api/reference/posts?kind=trains`, `/api/reference/sections?kind=trains`) возвращают **HTML-страницу** (Content-Type: text/html) вместо **JSON**.
- В ответе приходит `index.html` (1673 байта), а не массив данных.
- React-компонент ожидает JSON, получает HTML, и при попытке обработать данные падает → белый экран.

**Что не так:**
- Nginx не проксирует запросы к `/api/reference/*` на бэкенд для домена `ts-trip.com`.
- На доменах `ts-travel.by` и `ts-travel.online` это работает, значит проблема локальная — только в конфиге Nginx для `ts-trip.com`.
- В конфиге Nginx для `ts-trip.com` отсутствует или неправильно настроен `location /api/`.

**Что должно быть:**
- Все запросы к `/api/*` должны проксироваться на бэкенд: `http://app:4000/api/`.
- API должен возвращать JSON, а не HTML.
- Страницы `/blog`, `/reference`, `/guide` должны загружаться и отображать контент.

---

## Проблема 2: Цвет шапки на странице /routes

**Наблюдаемое поведение:**
- На `/routes` шапка (Главная, Маршруты, Справочная, Блог, Путеводитель, Войти) при скролле становится белой.
- Должна становиться цветной (как на главной странице после скролла) — в цветах сайта (сине-фиолетовая).

**Что не так:**
- Логика изменения цвета шапки на `/routes` отличается от логики на главной странице.
- В `Header.tsx` для `/routes` не применяются те же стили, что для главной.

**Что должно быть:**
- При скролле на `/routes` шапка должна становиться цветной (градиент или фон в цветах сайта).
- Обычная шапка (без скролла) — прозрачная или белая, как сейчас.

---

Важно: Обе проблемы должны быть решены так, чтобы изменения работали на всех трёх доменах (`ts-trip.com`, `ts-travel.by`, `ts-travel.online`). Конфигурации Nginx должны быть одинаковыми для всех доменов.
