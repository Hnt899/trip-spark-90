У меня есть проект trip-spark-90, развёрнутый на VPS (Ubuntu, Docker, Nginx). После выполнения команды `docker compose --env-file .env.vps up -d --build web app` сайты перестали открываться. Нужно срочно восстановить работоспособность и доделать три задачи.

## Общая ситуация

**Что произошло:**
- Выполнил команду `docker compose --env-file .env.vps up -d --build web app`
- После этого все сайты перестали открываться (ERR_CONNECTION_REFUSED или ERR_SSL_PROTOCOL_ERROR)
- Контейнеры запустились, но Nginx не отвечает

**Нужно:**
1. Восстановить доступность сайтов
2. Доделать три задачи (они не исправились)

---

## Задача 1: Страницы Справочная, Блог, Путеводитель не открываются на ts-trip.com (не исправилось)

**Наблюдаемое поведение:**
- На доменах `https://ts-travel.by` и `https://ts-travel.online` страницы `/reference`, `/blog`, `/guide` работают нормально.
- На домене `https://ts-trip.com` эти же страницы открываются пустыми. В консоли браузера (F12) видны ошибки, связанные с загрузкой данных.
- Автодополнение в форме поиска на `ts-trip.com` не работает.
- Проблема осталась после перезапуска.

**Что нужно сделать:**
- Проверить конфиг Nginx для `ts-trip.com` — возможно, он отличается от других доменов.
- Проверить, что `/api` и `/travelpayouts` проксируются на бэкенд.
- Проверить, что контейнер `app` работает и отвечает на запросы.
- Очистить кеш браузера или добавить `Cache-Control` в Nginx.

---

## Задача 2: Шапка с формой поиска на странице /routes (не исправилось)

**Наблюдаемое поведение:**
- На странице `/routes` шапка с формой поиска (Откуда, Куда, даты, пассажиры, кнопка «Найти») видна сразу при загрузке страницы.
- Она перекрывает верхнюю часть контента.
- На главной странице эта шапка появляется только после скролла.

**Что должно быть:**
- На `/routes` шапка с формой поиска должна появляться только после скролла до блока «Создавайте свои истории с TudaSuda».
- Обычная шапка (Главная, Маршруты, Справочная, Блог, Путеводитель, Войти) должна быть видна всегда.

**Что нужно сделать:**
- Проверить файл `src/components/Header.tsx`.
- Найти логику для страницы `/routes`.
- Исправить так, чтобы форма поиска появлялась только при скролле (как на главной).

---

## Задача 3: Данные для входа в админку (не подходят)

**Наблюдаемое поведение:**
- Данные `admin@trip-spark.test` / `Admin123!` не работают.
- При попытке входа в админ-панель ошибка «Неверный email или пароль» или «Ошибка сервера».

**Что нужно сделать:**
- Проверить, есть ли в базе данных пользователь с ролью `admin`.
- Если есть — сбросить пароль через bcrypt на `Admin123!`.
- Если нет — создать нового админа с email `admin@trip-spark.test` и паролем `Admin123!`.
- Убедиться, что в `.env.vps` есть `JWT_SECRET` и он передан в контейнер `app`.

---

## Важно

- Все изменения должны работать на всех трёх доменах: `ts-trip.com`, `ts-travel.by`, `ts-travel.online`.
- Конфигурации Nginx и код для этих доменов должны быть одинаковыми.
- После каждого изменения нужно проверять, что сайты открываются и задачи решены.

Напиши полный план действий с командами, которые нужно выполнить на сервере, а также необходимые изменения в коде и конфигах.
